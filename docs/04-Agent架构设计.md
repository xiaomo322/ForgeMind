# ForgeMind Agent 架构设计

**版本：V0.1**  
**状态：核心已确定**

## 1. Agent 定位

Agent 是 ForgeMind 的思考和决策者，不直接替代工具执行项目操作。

## 2. 核心职责

- 理解用户需求；
- 分析项目和任务相关代码；
- 识别候选问题与已确认问题；
- 制定解决方案；
- 选择下一步 Action 和 Tool；
- 判断决策风险与是否需要用户确认；
- 根据 Observation 更新认知；
- 判断任务是否完成。

## 3. 决策原则

```text
小决策 → Agent 自主继续
大决策 → 用户确认后继续
风险不明确 → 按高风险处理并请求确认
```

## 4. 认知状态

问题判断可以经历：

```text
未知 → 候选 → 怀疑 → 验证 → 确认
```

Agent 不应把尚未验证的候选问题当作已确认事实。

## 5. 安全边界

Agent 可以先进行风险判断，但 LLM 判断不构成最终安全边界。所有高风险 Action 必须经过 Runtime 的确定性拦截。
