# ForgeMind 无文件聊天任务设计

## 目标

用户无需先上传 Python 文件或 ZIP，只输入问题也能创建并运行 ForgeMind 任务。任务仍然绑定持久工作区，后续可以继续上传附件并逐步变成代码任务。

## 设计

- `CreateTaskRequest.workspace_id` 改为可选。
- 请求提供 `workspace_id` 时继续绑定已有工作区；未提供时由服务端创建空工作区，再创建任务。
- 空工作区与普通工作区使用相同的 `workspace_<uuid>` 标识、持久目录、任务历史、文件列表和 ZIP 下载流程。
- `UploadedWorkspace` 允许 `files=()`、`file_count=0`，但原有多文件上传接口仍拒绝空上传。
- 新建页把文件选择标记为可选；只有用户实际选择文件时才调用上传接口，没有文件时直接创建任务。
- 后续聊天附件保持现有安全流程：先暂存，进入 Agent 安全边界后再发布到空工作区。

## 验证

- 存储层证明空工作区在重启后仍可解析。
- API 证明只提交 `original_request` 会创建空工作区和持久任务。
- API 证明显式 workspace_id 的原有流程不变。
- 前端证明只填写问题不会调用文件上传接口，并能进入任务工作台。
- 完整 Python、前端和生产构建回归通过。
