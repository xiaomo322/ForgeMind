# Edit File V0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现一个绑定已读取版本、逐 Action 获得用户确认、只执行一次精确替换并以同目录临时文件原子写回的 `edit_file` 完整闭环。

**Architecture:** Agent 产生严格 Decision，Runtime 分配 action_id、登记不可变 AcceptedAction 并创建保存完整参数快照的权限请求。用户批准后，Runtime 取回原 Action，执行路径和无变化检查，再由 Tool 读取、校验版本、构造唯一替换、暂存并原子切换文件；Runtime 把实际结果或阶段错误登记为唯一终态 Observation。

**Tech Stack:** Python 3.13、Pydantic v2、pathlib、tempfile、os.replace、difflib、pytest。

## Global Constraints

- 只修改项目根目录内已经存在的 UTF-8 文本文件，不创建新文件。
- 文件最大 64 KiB；`old_text` 非空并且必须恰好匹配一次。
- `new_text` 必填但可以为空；`old_text == new_text` 在 Tool 调用前拒绝。
- `expected_version` 必填，基于完整原始字节的 SHA-256。
- 每个 edit_file Action 必须获得一次绑定完整参数快照的独立用户确认。
- 使用目标同目录临时文件、flush、fsync、权限复制和 `os.replace`。
- V0.1 不支持正则、模糊匹配、全部替换、多文件事务或跨进程完全无竞争保证。
- 每个生产代码切片遵循 RED → GREEN → REFACTOR；核心函数先写中文步骤注释，由学习者实现。

    after_version: str = Field(min_length=1)
    replacement_count: Literal[1]
    diff: str = Field(min_length=1)

    @model_validator(mode="after")

```python
@dataclass(frozen=True)
class PreparedEdit:
    before_bytes: bytes
    after_bytes: bytes
    before_version: str
    after_version: str
    diff: str


def prepare_edit_from_snapshot(
    action: AcceptedEditFileToolAction,
    *,
    content: bytes,
) -> PreparedEdit:
    actual_version = calculate_content_version(content)
    if actual_version != action.arguments.expected_version:
        raise EditFileVersionMismatchError(
            action.arguments.expected_version,
            actual_version,
        )
    text = content.decode("utf-8")
    match_count = text.count(action.arguments.old_text)
    if match_count == 0:
        raise EditTargetNotFoundError
    if match_count > 1:
        raise EditTargetAmbiguousError(match_count)
    new_text = text.replace(
        action.arguments.old_text,
        action.arguments.new_text,
        1,
    )
    after_bytes = new_text.encode("utf-8")
    diff = "".join(
        difflib.unified_diff(
            text.splitlines(keepends=True),
            new_text.splitlines(keepends=True),
            fromfile=f"{action.arguments.path}.before",
            tofile=f"{action.arguments.path}.after",
        )
    )
    return PreparedEdit(
        before_bytes=content,
        after_bytes=after_bytes,
        before_version=actual_version,
        after_version=calculate_content_version(after_bytes),
        diff=diff,
    )
```

diff 的 fromfile/tofile 都使用 Action.path，分别附加 `.before` / `.after`；使用 `splitlines(keepends=True)` 保留真实换行。

- [ ] **Step 3: 实现原子替换**

核心顺序：读取目标权限模式；用 `NamedTemporaryFile(delete=False, dir=path.parent, prefix=".forgemind-edit-")` 写入 after_bytes；flush、fsync；chmod 临时文件；重新读取目标并比较 `prepared.before_version`；调用 `os.replace`。`finally` 只删除仍然存在的本次临时文件。

```python
temporary_path: Path | None = None
try:
    with tempfile.NamedTemporaryFile(
        mode="wb",
        delete=False,
        dir=path.parent,
        prefix=".forgemind-edit-",
    ) as temporary_file:
        temporary_path = Path(temporary_file.name)
        temporary_file.write(prepared.after_bytes)
        temporary_file.flush()
        os.fsync(temporary_file.fileno())
    temporary_path.chmod(stat.S_IMODE(path.stat().st_mode))
    current_version = calculate_content_version(read_file_bytes(path))
    if current_version != prepared.before_version:
        raise EditFileVersionChangedError(
            prepared.before_version,
            current_version,
        )
    os.replace(temporary_path, path)
except OSError as exc:
    raise EditFileWriteError(path, exc) from exc
finally:
    if temporary_path is not None and temporary_path.exists():
        temporary_path.unlink()
```

版本变化异常必须在通用 OSError 转换之外保留自己的类型。
