# ForgeMind 项目需求规格说明

**版本：V1.0**  
**状态：已确认**

## 1. 项目概述

ForgeMind 是一个面向 Python / AI 应用开发者的项目级研发 Agent，在用户授权范围内理解开发需求和项目上下文，完成代码读取、修改、执行和测试，并反馈验证结果与风险。

## 2. 目标用户

Python 开发者和 AI 应用开发者。

## 3. 用户痛点

- 不熟悉现有项目结构和代码逻辑；
- 面对陌生项目或技术时定位问题耗时；
- 自行修改项目消耗大量时间；
- 修改后难以确认真实效果和潜在风险。

## 4. 核心目标

帮助开发者完成具体的软件开发任务，并对修改结果进行验证。

## 5. MVP 核心场景

用户请求修复一个多文件 Python 项目中的简单 Bug。ForgeMind 依次理解需求、分析任务相关上下文、搜索并读取代码、制定方案、按风险请求确认、修改代码、运行程序和测试，最后判断结果并报告风险。

## 6. Agent 与工具职责

- Agent 负责思考、理解、分析、规划、决策和判断；
- 工具负责读取、修改和执行；
- Agent 决定修改内容，工具按指令执行。

## 7. 自主与确认

- 小决策由 Agent 自主继续；
- 大决策交给用户确认后再继续；
- 删除数据、生产数据库操作、删除大量文件、生产部署等高风险操作必须确认。

## 8. 上下文策略

默认按任务需要逐步获取相关上下文，不无差别读取整个项目。

## 9. 完成标准

任务完成必须覆盖：需求满足、代码检查、程序运行、相关测试、必要的新测试和风险说明。无法验证的内容必须明确说明。

## 10. 第一阶段暂不做

暂不引入 RAG、Milvus、Multi-Agent，也暂不处理复杂业务需求。

## 11. 核心原则

安全优先于效率。Agent 的判断不是最终安全边界，执行前必须由 Runtime 进行确定性权限与安全检查。
