## 2026-10-08：Codex 式持续对话与附件

- Web 任务增加普通后续消息入口；消息使用服务器分配的 ID 和任务内连续序号持久化，`TaskRecord.original_request` 不被覆盖。
- queued 消息只在完整 Agent/Tool 步骤之间应用；Agent Context 独立记录消息总数、省略数和历史完整标记。
- 任务运行期间追加的 Python 文件先写入隔离暂存目录，返回真实大小和 SHA-256，但不会立即出现在活动 Workspace。
- 安全边界发布附件时核对源文件或目标文件哈希；进程在移动文件后中断时，可以根据已发布目标的哈希继续登记消息应用事实。
- 活动文件和同一 Workspace 的暂存文件共同执行不区分大小写的重名保护，避免覆盖 Agent 已读取或修改的内容。
- `COMPLETED` 与 `BLOCKED` 任务收到后续消息时，在同一 SQLite 事务中保存消息并追加 `RUNNING` 状态；`CANCELLED` 继续拒绝恢复。
- FastAPI 新增任务附件暂存、文件列表和后续消息接口；公开响应只包含 Workspace 相对文件名、大小、SHA-256 和状态，不返回服务器绝对路径或暂存令牌。
- React 页面改为单列对话体验，增加固定消息输入框、附件选择与移除、queued/applied 标记和响应式项目文件抽屉；提问仍使用原问题 ID，权限仍只能通过权限卡片决定。
- 新增端到端 API 测试验证暂存文件在安全边界前不可见、应用后进入 Workspace、消息进入下一轮 Context，并且公开结果不泄露存储根目录。
