# ForgeMind Tool 工具协议

**版本：V0.1**  
**状态：初步确定**

## 1. 工具职责

Tool 只负责执行明确、结构化的操作。Tool 不负责理解“帮我修复登录功能”这类自然语言任务，也不自行决定修改方案。

## 2. MVP 工具

| Tool | 职责 | 风险 |
|---|---|---|
| `read_file` | 读取指定任务相关文件 | 低 |
| `search_code` | 搜索文件、函数、类或文本 | 低 |
| `edit_file` | 按 Agent 指定内容修改文件 | 中 |
| `run_command` | 执行 Agent 指定的程序或命令 | 按命令判断 |
| `run_tests` | 执行相关测试 | 低到中 |

## 3. Tool Schema 要求

每个 Tool 后续必须明确规定：名称和用途、输入参数及类型、返回值、参数缺失和执行失败情况、权限要求与风险等级。

## 4. 调用规则

```text
Agent 生成 Action
  ↓
Runtime 校验结构和参数
  ↓
权限与安全检查
  ↓
Tool 执行
  ↓
返回 Observation
```

Runtime 不猜测意图、不自动补全参数。参数不完整时直接返回明确错误，由 Agent 重新决策。

## 5. 修改边界

`edit_file` 不应默认允许任意文件、任意范围修改。目标路径、修改范围和修改内容必须明确，并经过 Runtime 权限与安全检查。
